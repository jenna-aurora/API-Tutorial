Day 1-Reflection

Something challenging

Indenting by hand is something challenging, most when the API is lenghty. JSON is not forgiving with punctuation. A request could be challenging to call without an object and its property.

A trap to watch for

When it comes to a trap to watch for, it comes down to proof reading. The dot notation practice calls for context clues. API and its indentation for a pretty format.
